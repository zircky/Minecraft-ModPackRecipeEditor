## Определение версии и загрузчика

- Prism и MultiMC — `mmc-pack.json`, компоненты игры и загрузчика.
- CurseForge — `manifest.json` или `minecraftinstance.json`.
- Modrinth — локальный `modrinth.index.json`, раздел `dependencies`. Архив `.mrpack` следует распаковать или выбрать папку установленной сборки. [Спецификация Modrinth](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack).
- Vanilla и производные профили — явный `version.json`, включая `inheritsFrom` и координаты библиотек. Выбор активной версии из нескольких установленных профилей не угадывается.
- Forge, NeoForge, Fabric и Quilt определяются отдельно от Minecraft Version. Если в явных данных есть противоречие, показывается `UNKNOWN` и сохраняются источники диагностики. Наличие JAR мода не доказывает, какой загрузчик установлен.
- При неизвестной версии JavaFX запрашивает номер релиза для текущего импорта. Отмена оставляет версию неизвестной и позволяет индексировать ресурсы. Ручной выбор действует в текущем сеансе. Схема файла проекта не менялась.

## Проверяемая матрица

| Версия | Профиль | Возможность после импорта |
| --- | --- | --- |
| 1.7.10 Forge | Legacy | Метаданные и статические ресурсы в доступных форматах. Программно зарегистрированные рецепты, старые GT и GTNH потребуют отдельной интеграции. |
| 1.12.2 Forge | Early JSON | Поиск и просмотр JSON из `assets/<namespace>/recipes/`. |
| 1.13–1.20.x | Datapack | Поиск и просмотр JSON из `data/<namespace>/recipes/`. Интеграционный пример 1.16.5. |
| 1.20.1 Forge | Datapack и существующая семантика | Существующие поддерживаемые парсеры и редактирование. Для экспорта действуют проверки выбранного экспортёра. |
| 1.21.1 NeoForge | Modern Datapack | Поиск и просмотр JSON из `data/<namespace>/recipe/`. Прочие числовые релизы серии 1.x от 1.21 получают профиль обнаружения. |
| Неизвестная версия или неоднозначный адаптер | Статические ресурсы | Каталог ресурсов без поиска рецептов по неподтверждённому формату. |

JSON вне проверенного профиля доступен для чтения. Поддержка layout сама по себе не даёт семантику рецепта, редактирование или экспорт. Старые `mcmod.info` и `.lang`, скриптовая регистрация, снапшоты Minecraft и новые версии вне серии 1.x требуют отдельных адаптеров или источников данных. Проверки на новых версиях используют тестовые файлы, живые клиенты этих версий не запускались.

## Проверки

- `./gradlew.bat clean build` — успешно, 3 мин 9 с. Проверены 12 модулей и отсутствие циклов.
- `./gradlew.bat test` — успешно, 18 с с переиспользованием результатов. 379 unit-тестов, два пропуска из-за недоступных символических ссылок, 111 интеграционных тестов. Ошибок нет.
- `MinecraftVersionDetectorTest` и `ModLoaderDetectorTest` проверяют источники версии, независимые версии загрузчика, неизвестные значения и конфликтующие метаданные.
- `MinecraftCompatibilityRegistryTest` проверяет поколения, ограничения редактирования и отказ при несовместимом или неоднозначном адаптере.
- `RecipeFormatAdapterTest` проверяет полный статический импорт тестовых папок и JAR для пяти версий без клиента. Исходный JSON, вложенные неизвестные поля и путь к источнику сохранены. Legacy не интерпретирует современный datapack как регистрацию рецепта.

Коммиты производственного кода — `bf60e3d`, `d934b9d`, `b74c91d`. Push не выполнялся. Существующее пользовательское изменение резервного файла проекта осталось в рабочей папке.
