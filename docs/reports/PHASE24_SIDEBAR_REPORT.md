# Phase 24 — Правая панель редактора и выбор машины GregTech

Ветка `feat/phase-24-universal-runtime-recipe-editor`, версия `1.1.4-alpha`.

## Причина и реализация

В прежней форме тип машины выводился как текст. У выбора не было списка значений или обработчика, который применял бы новый тип к черновику. Поддержка редактирования также определялась проверенным профилем GTCEu 7.1.4. У старых снимков отсутствовали пределы входов и выходов на уровне зарегистрированных типов, поэтому включение ComboBox само по себе не позволило бы проверить миграцию.

В текущем checkout отдельного компонента Statistics Sidebar нет. За основу взят `SplitPane` правой панели Resource Browser. Runtime Recipe Browser показывает выбранный рецепт справа и открывает там же поддерживаемый редактор. Панель закрывается и изменяет ширину, форма прокручивается. При попытке покинуть изменённый черновик редактор запрашивает подтверждение. Черновики используют существующие формы и Ingredient Picker. Доступность редактирования зависит от данных и поддержки адаптера, поэтому подключение к Companion для открытия сохранённого снимка не требуется.

Companion читает максимальное число слотов из публичных карт GTCEu для проверенных ABI. Каталог получает типы через Runtime Registry и свидетельства из рецептов в снимке. Записи с одинаковым ID объединяются, а сторонние пространства имён сохраняются. При наличии используются название и источник из снимка. При отсутствии имени отображается ID, при отсутствии источника отображается `UNKNOWN`.

Миграция сохраняет содержимое черновика и показывает превышения по каждому типу слота. Неизвестный лимит, непроверенная категория и неподдерживаемые свойства блокируют сохранение. Когда проверенный KubeJS builder требует новый ID, пользователь вводит его явно. Замена хранится в существующем ChangeSet как связанные `DELETE` и `CREATE`. Undo/Redo обрабатывает пару за одну команду. Экспорт блокирует неполную пару и удаляет исходный рецепт перед регистрацией нового.

## Проверки

- `gradlew.bat clean build` и `gradlew.bat test` прошли на Java 21 с локальным Gradle-кэшем и изолированным каталогом сборки. Из 388 unit-тестов прошло 386, два теста символических ссылок на Windows пропущены. Прошли все 112 интеграционных тестов. Проверка архитектуры подтвердила отсутствие циклов в 12 модулях.
- Новые тесты проверяют открытие, переключение и повторное открытие правой панели без Companion, каталог типов дополнений, сохранение свойств при миграции, пределы слотов, Undo/Redo связанной замены и порядок операций в KubeJS. В ходе чистой сборки исправлена гонка в диагностике при инвалидировании кэша превью после обновления файлов ресурсов.
- Gradle-сборка Forge Companion прошла на Java 17. SHA-256 полученного JAR `012235C191B633C58B42C4797E2ADC9256458FF589525D9206F1DF1E48157C13`.
- Запущенный ISG прошёл аутентификацию по Companion Protocol 1 с установленным Companion `0.1.0`. `LiveSnapshotPersistenceTest` остановился на запросе `GET_REGISTRIES` после 300 секунд сбора клиентских имён и текстур (`Synchronization deadline exceeded`). Новый снимок не опубликован. Minecraft продолжил работать с прежним JAR, игровые файлы не изменялись.
- `RuntimeRecipeTypeDiscoveryTest` повторно открыл ранее сохранённый снимок ISG в SQLite без сокета. Прочитаны 211 типов и 98 937 рецептов. Редактирование панели и миграция проверены автоматическими тестами на данных с известной схемой.

Полный перечень приведён в [списке изменённых файлов](PHASE24_SIDEBAR_FILES.txt).

## Ограничения

- Запись и KubeJS-экспорт смены типа проверены автоматическими тестами для профиля GTCEu `7.1.4` с KubeJS `2001.6.4-build.120` и типов, поддержанных существующим адаптером. Найденные Mixer и типы дополнений доступны для просмотра, если их контракт экспорта неизвестен.
- В установленной сборке ISG используется GTCEu `8.0.0-SNAPSHOT+e24b238`. Новая версия Companion умеет читать пределы слотов этого ABI. Запись и экспорт его машинных рецептов требуют отдельной проверки сериализатора и KubeJS API. Runtime-определения без сопоставимого исходника проекта доступны для просмотра и, при наличии адаптера, для копирования.
- Старые снимки открываются. Для появления новых лимитов требуется получить свежий снимок с обновлённым Companion. Готовый JAR находится в `minecraft-companions/forge-1.20.1/build/libs/mre_companion-forge-1.20.1-0.1.0.jar`. Для его установки и проверки понадобится перезапуск Minecraft пользователем.
