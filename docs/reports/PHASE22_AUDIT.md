# Phase 22 — Аудит перед внедрением постоянного хранилища

База работы — `fix/phase-21-client-item-preview-pipeline` (`03e5894`). В ней уже есть клиентский рендеринг иконок, восстановление превью при подключении и инструменты проверки передачи PNG.

| Участок | Существующее поведение |
| --- | --- |
| Companion, протокол и реестры | `ForgeSnapshotProvider` собирает данные авторитетного локального мира или сервера. `RuntimeRegistryScanner`, `RuntimeTagCollector` и `ClientPresentationCollector` передают реестры, теги и доступную информацию для отображения. `CompanionConnectionService` проверяет среду, идентификатор и поколение снимка по всем наборам. |
| Рецепты и материалы | `RuntimeRecipeScanner` читает RecipeManager и поддерживаемые GTCEu category/proxy коллекции. `GregTechRuntimeRecipeAdapter` сохраняет доступные свойства через кодек поддерживаемой версии. `GregTechMaterialCollector` несёт зарегистрированные формы материалов и их метаданные. Неизвестное происхождение остаётся неизвестным. |
| Runtime Snapshot | `RuntimeSnapshotService` читает и записывает переносимый ZIP `.mresnapshot` с JSONL и контрольными суммами. Данные можно повторно открыть вручную. До Phase 22 снимки не индексировались по содержимому сборки. |
| Слияние и каталог | `RegistryMergeService` и `RecipeMergeService` сопоставляют статические и runtime-данные. `MainWindow.applyRuntime` проверяет импортированную среду и передаёт доказательства редактору. Нормализованные runtime-рецепты доступны для чтения. |
| Изменения проекта | `RecipeEditorService` ведёт `RecipeChangeSet` отдельно от оригиналов и карантинит конфликтующие правки. `FileProjectPersistence` хранит путь к сборке и пользовательские изменения. Заново открытый проект не восстанавливает из своего файла runtime-данные. |
| Изображения | `InventoryPreviewProvider` получает нативные PNG от клиента, держит ограниченный кэш в памяти и использует статическое приближение при недоступности клиента. Нативные PNG из просмотра пока не переживают завершение редактора. |
| Экспорт | `RecipeExportService` работает с поддерживаемыми изменениями проекта. `KubeJsJavaScriptExporter` уже генерирует JS через существующие адаптеры и проверки возможностей. Неподдерживаемая семантика не покрывается самим фактом сохранения снимка. |
| Runtime UI | `RuntimeIntegrationView` управляет подключением, сбором, открытием переносимого снимка и просмотром нативной иконки. Отключение сохраняет загруженный снимок в памяти текущего окна. |

SQLite добавлена как локальное хранилище полных runtime-данных. Формат проекта, переносимый снимок, протокол и Forge-сборщик остаются совместимыми с текущими процессами.
